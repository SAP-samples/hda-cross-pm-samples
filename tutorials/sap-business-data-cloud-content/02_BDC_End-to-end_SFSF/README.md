# Transform business data into AI-supported insights


## Description

## Overview

This hands-on workshop is designed for a data scientist/ analyst persona who want to gain practical expertise with SAP Business Data Cloud. Participants will explore how to consume SAP-managed data products from our partner ecosystems, create and publish a custom data product to SAP BDC catalog and derive insights from custom reporting. We will also get a sneak peek on how Joule agents can ease up the process.

## Requirements

- Google Chrome Browser or Microsoft Edge based on the Chromium engine
- Access to this GitHub repository
