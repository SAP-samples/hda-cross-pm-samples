# Create a custom data product out of SAP BW (READ-ONLY, PRODUCT TOUR)

## Overview
In this exercise, we will learn how a custom data product can be created from SAP BW.
For the puprose of this use case, we need the Business Partner data and Dun & Bradstreet Credit risk data coming in from SAP BW. In this exercise, we will learn the following:
1. Use BW Data Product Generator to expose the data from SAP BW into SAP Datasphere
2. Land the data into Object storage in SAP Datasphere
3. Create a custom Data product using the Data Sharing Cockpit in SAP Datasphere
4. Share the custom data product from SAP BDC Catalog into SAP Databricks
